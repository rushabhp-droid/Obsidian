Clickable prototype of the consumer app, built from stock Material 3 parts so it maps one to one onto Jetpack Compose. Everything inside the phone works: navigation, filters, report, trust, rules and settings.

Try this

  1. Unlock, open the message from Rahul and tap Report as scam. The link moves to Rules, Blocked.
  2. Open the SMS from the unknown number and trust the link. It appears under Rules, Trusted.
  3. In Settings, turn off Notification access to see the first run state on Home.
  4. Turn on High contrast black in Settings, or use the switch above.

Sample data. Every name, number and link is an example. Checking states follow the product rules: a link that is still being checked is never shown as safe, and safe is never shown in green.
